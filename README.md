# Glam Studio ✨

Jeu de maquillage animé pour filles, 100 % HTML/SVG/JS, sans dépendance.

- Teint, blush, fards à paupières, eyeliner + cils, couleur des yeux, rouge à lèvres
- 6 coiffures × 8 couleurs de cheveux, boucles d'oreilles, lunettes, couronne / nœud / fleur / bandeau, stickers
- Pinceau animé, étincelles, clignement des yeux, points glam, look surprise, annuler, photo polaroid

Ouvrir `index.html` dans un navigateur, ou déployer sur GitHub Pages.
